# Disposable calculator workspace

Copy this folder into `workspaces/calculator` and initialize it as its own Git repository
using the PowerShell commands in the main README. Don Codino never initializes or commits
your real workspaces automatically.

> Build a Python calculator supporting addition, subtraction, multiplication, and division,
> with pytest tests including division by zero.

Start with this clean seed, refine the request in the dashboard, edit the plan, and approve it.
